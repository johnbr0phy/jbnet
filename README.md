# jbnet

Personal site for johnbrophy.net. One HTML file (`index.html`) on GitHub Pages.

## Featured posts

- Each section's "Featured posts" list holds at most 5 posts.
- Not every new post is featured. Only add one if it displaces a weaker pick.
- Choose for recruiter relevance: shipped products, real users and metrics, AI applied at work, product and process learning. Fun experiments stay in the feed but not in the list.

## Deploying

- Merging to `main` triggers the GitHub Pages "pages build and deployment" workflow (normally under a minute).
- If the deploy job times out on GitHub's side, re-running it can keep failing. Push a new commit to `main` to start a fresh deployment instead.
